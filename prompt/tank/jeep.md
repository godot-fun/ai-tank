生成一个用于 Top-Down 2D 游戏的白色军用吉普车精灵。

【画布尺寸】
512×512 像素。

【美术风格】
高精度像素风（High-Res / Modern Pixel Art），细节丰富，像素清晰，具有现代像素游戏质感。
保持与军事科幻坦克精灵统一的像素艺术风格。
边缘清晰，轮廓明确，像素细节丰富。
适合作为 Top-Down 动作游戏 Sprite 使用。

【视角要求】
严格正交俯视视角（90°垂直向下）。
镜头正对吉普车顶部。
完全垂直俯视，没有透视效果。
没有倾斜角度。
不能出现 45°视角、等距视角或斜视角。
看不到任何车辆侧面结构。
不显示车门侧面、车轮侧面、底盘侧面。
车辆长宽比例保持真实，不发生透视缩短。

【方向要求】
车辆必须朝向画面上方（North / Up Direction）。
车头位于图片上方。
前保险杠、前灯、发动机舱朝向顶部。
车辆尾部、备用轮胎、后部装备箱位于图片下方。
保持与坦克单位方向一致。
不要车头朝下，不要倒车方向朝上。

【主题风格】
军事科幻风。
未来战场中的轻型侦察攻击车辆。
白色装甲军用吉普车（White Military Jeep / Arctic Tactical Recon Vehicle）。
具有高速机动、侦察、突袭能力的视觉特点。

【车辆设计】
- 方正硬朗的军事越野车结构。
- 轻型装甲吉普车外形。
- 四轮布局，轮胎只显示顶部结构。
- 顶部安装轻型武器系统，例如机枪炮塔或能量武器模块。
- 具有装甲板、防护栏、天线、备用装备箱、铆钉等军事细节。
- 车身结构简洁，避免过度复杂。
- 具有未来军事科技感。
- 适合 Top-Down 动作游戏中的高速移动单位。

【颜色】
主体颜色为纯白色（White / Arctic White）。
搭配浅灰色装甲分层。
金属部件使用深灰色（Gunmetal Gray）。
加入少量冰蓝色科技灯光或能量模块作为点缀。
整体颜色干净、高识别度。
避免复杂迷彩图案。
避免大面积黑色覆盖。

【构图】
单个吉普车居中。
完整显示整个车辆。
车头朝上。
保持垂直方向排列。
白色背景。
无阴影。
无地面。
无环境元素。
无文字。
无 UI 元素。
无其他车辆。

【游戏性要求】
轮廓清晰。
具有经典《坦克大战》风格的方正结构。
适合 Top-Down 2D 动作游戏。
远距离可以快速识别为轻型车辆单位。
与坦克、装甲车、敌方单位保持统一精灵风格。
适合作为游戏角色 Sprite。

【禁止元素】
不要透视。
不要斜45度角。
不要等距视角。
不要车辆侧视图。
不要真实照片风格。
不要 3D 渲染风格。
不要复杂背景。
不要多个车辆。
不要人物。
不要驾驶员。
不要车头朝下。
不要前脸朝向画面底部。
