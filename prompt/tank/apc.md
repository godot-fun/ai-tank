生成一个用于 Top-Down 2D 游戏的蓝色军用装甲车精灵。

【画布尺寸】
512×512 像素。

【美术风格】
高精度像素风（High-Res / Modern Pixel Art），细节丰富，像素清晰，具有现代像素游戏质感。
保持与军事科幻坦克、吉普车精灵统一的像素艺术风格。
边缘清晰，轮廓明确，像素细节丰富。
适合作为 Top-Down 动作游戏 Sprite 使用。

【视角要求】
严格正交俯视视角（90°垂直向下）。
镜头正对装甲车顶部。
完全垂直俯视，没有透视效果。
没有倾斜角度。
不能出现 45°视角、等距视角或斜视角。
看不到任何车辆侧面结构。
不显示车门侧面、车轮侧面、底盘侧面。
车辆长宽比例保持真实，不发生透视缩短。

【方向要求】
车辆必须朝向画面上方（North / Up Direction）。
车头位于图片上方。
前装甲、前灯、发动机舱朝向顶部。
车辆尾部、后门舱、排气或装备舱位于图片下方。
保持与坦克、吉普单位方向一致。
不要车头朝下，不要倒车方向朝上。

【主题风格】
军事科幻风。
未来战场中的中型武装装甲车（Armed APC / IFV / Infantry Fighting Vehicle）。
蓝色军用装甲车（Blue Military Armored Fighting Vehicle）。
具有中等装甲防护、中速机动、持续火力输出的视觉特点。
这是会开火作战的战斗单位，不是无武装运输车。
外形必须明显区别于坦克（履带重炮）和吉普车（轻型四轮越野）。

【车辆设计】
- 方正硬朗的箱式装甲车结构，车身比吉普更厚重、更宽，但车身要短、紧凑。
- 中型武装装甲车外形，不是主战坦克，也不是轻型吉普。
- 整体接近正方形或略扁的矩形，车头到车尾长度明显短于细长运兵车。
- 不要细长巴士式车身，不要加长货厢，不要前后拖尾过长。
- 四轮或六轮布局（优先四轮或短轴距六轮），轮胎只显示顶部结构；不要履带。
- 必须配备清晰可见的火力系统：顶部安装中型炮塔或遥控武器站。
- 武器朝向车头方向（画面上方），炮口 / 枪口清晰可见，适合作为游戏开火单位。
- 武器类型示例：中口径机炮、双联机枪、能量脉冲炮；火力感强于吉普轻机枪，弱于坦克主炮。
- 炮塔体量明显小于坦克主炮塔，但仍是车辆顶部的核心视觉焦点。
- 可带弹药箱、武器传感器、冷却鳍片、能量模块等强化火力感的细节。
- 具有装甲板分层、观察窗盖、舱盖、天线、铆钉、工业警示条纹等军事细节。
- 车身后部可有短舱门或矩形舱盖，保留装甲运载识别度，但不要因此拉长车身。
- 车身结构简洁，避免过度复杂。
- 具有未来军事科技感。
- 适合 Top-Down 动作游戏中的中型火力抗压单位。

【颜色】
主体颜色为纯蓝色，与我方蓝色坦克同色系，方便阵营识别。
搭配深蓝与浅蓝装甲分层，形成清晰块面。
金属部件使用深灰色（Gunmetal Gray）。
可加入少量浅蓝科技灯光或能量模块作为点缀。
整体颜色干净、高识别度。
避免复杂迷彩图案。
避免大面积黑色覆盖。
避免红色、绿色、白色主体（那些颜色留给其他单位）。

【构图】
单个装甲车居中。
完整显示整个车辆。
车头朝上。
保持垂直方向排列。
白色背景。
无阴影。
无地面。
无环境元素。
无文字。
无 UI 元素。
无其他车辆。

【游戏性要求】
轮廓清晰。
具有经典《坦克大战》风格的方正结构。
适合 Top-Down 2D 动作游戏。
远距离可以快速识别为「带炮塔的短身中型装甲车」战斗单位。
必须一眼看出有火力：顶部武器 / 炮口清晰可辨。
车身短而厚，不要细长；俯视轮廓接近坦克占地，但外形仍是轮式装甲车。
视觉上介于吉普（轻、快、火力弱）与坦克（重、主炮大）之间：有火力，但炮塔更小。
与坦克、吉普车、敌方单位保持统一精灵风格。
适合作为游戏角色 Sprite。

【禁止元素】
不要透视。
不要斜45度角。
不要等距视角。
不要车辆侧视图。
不要真实照片风格。
不要 3D 渲染风格。
不要复杂背景。
不要多个车辆。
不要人物。
不要驾驶员。
不要车头朝下。
不要前脸朝向画面底部。
不要履带。
不要大型坦克主炮塔。
不要细长车身、加长运兵舱、巴士式或卡车货厢式比例。
不要无武器的纯运输车外形。
不要只有天线/舱盖、没有炮口或枪口。
不要吉普车那种短小敞篷越野车外形。
