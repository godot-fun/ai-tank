Top-Down 2D 坦克大战游戏子弹命中爆炸效果序列帧动画。

【美术风格】
高精度现代像素风（High-Res / Modern Pixel Art），
细节丰富，像素清晰，边缘锐利，
具有现代像素游戏的精致质感。

【主题风格】
军事科幻风，适用于坦克射击游戏。

【动画要求】
制作一个坦克炮弹击中目标后的爆炸特效 Sprite Sheet。

16帧动画，
4×4排列方式，
每一帧尺寸完全一致。

【动画过程】
第1帧：
子弹撞击瞬间，出现明亮白色冲击闪光和少量火花。

第2-5帧：
爆炸快速展开，中心白色高亮，外围出现黄色、橙色火焰，伴随碎片飞散。

第6-10帧：
爆炸达到最大范围，大量火焰、火星、金属碎片向外扩散。

第11-14帧：
火焰逐渐减弱，出现少量黑灰色烟雾和残留火星。

第15-16帧：
烟雾消散，粒子逐渐消失，结束动画。

【视角要求】
严格90度俯视角（Top-Down View）。
正上方观察。
无透视。
无侧面视角。

【背景要求】
纯白色背景（Pure White Background）。
背景颜色为 #FFFFFF。
每一帧都使用统一白色背景。
爆炸效果位于画面中心。

【游戏用途】
用于 Godot / Unity 2D 游戏中的爆炸序列帧动画。
适合坦克大战、军事射击类游戏。

不要黑色背景。
