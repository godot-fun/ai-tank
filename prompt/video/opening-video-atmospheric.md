# 《AI TANK》开场动画 — 氛围诗意 / 极简自由发挥版

为 Godot 游戏《AI TANK》生成开场动画。题材仍是坦克战，但允许高度抽象、诗意、极简的视觉语言。尽量自由发挥。
不依赖参考图。

【必须保留】
- 能辨认出「坦克」与「蓝 / 浅绿」我方意象（可为剪影、几何体、光点轮廓，但不要完全不可读）。
- 情绪：压迫或孤寂 → 决心 / 对抗将起 → 标题 `AI TANK`。
- 1920×1080，约 10～12 秒。

【风格方向（最大自由度）】
雾、剪影、负空间、几何战场、粒子尘埃、单色或双色限制调色、慢镜、超远景小点坦克、象征性爆炸光斑……皆可。
可接近实验动画、动态海报、音乐可视化式运动图形，只要最终落回游戏开场的「战争将至」。
镜头、节奏、是否出现具体敌车、是否出现基地——全部可选。

【叙事】
不需要完整战斗；一个强烈意象 + 标题即可。宁可少而准，不要堆砌信息。

【禁止】
真人面部、血腥、真实国旗/军徽、复杂游戏 UI、水印、旁白、完全抽象到与坦克/战争无关。

【用途】
可选 Opening 变体（偏艺术向）。
