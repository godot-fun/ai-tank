# 《AI TANK》开场参考图 — 柔和独立游戏像素风

生成一张用于《AI TANK》开场动画的参考静帧（风格 / 高潮构图锁定图；不作视频首帧）。

【输出规格】
分辨率：1920×1080（16:9）。
单张静帧，非序列、非拼图。
文件命名建议 `tank-opening-ref.png`。

【用途】
作为后续开场视频的风格、配色、单位造型与高潮构图锁定参考（不作 I2V 首帧）。
画面应是「双方交火高潮定格」瞬间，信息完整，供视频中后段定格对齐。

【美术风格】
柔和独立游戏像素风（Soft Indie Pixel）：像素清晰，但边缘略圆润、色调偏暖灰绿。
氛围像现代叙事向独立游戏战场插画，而非硬核军事模拟。
细节中等：装甲有轻微分色，草地与尘烟有柔和抖动感，爆炸偏「游戏特效」而非写实火球。
整体调色：雾绿战场、柔蓝与薄荷绿我方、炭黑 / 乳白 / 珊瑚红敌方、琥珀橙爆炸。
不要写实 CGI，不要粗糙低清马赛克，不要赛博霓虹。

【视角要求】
严格正交俯视（90° 垂直向下）。
镜头正对战场顶部。
没有透视、没有倾斜、没有 45° / 等距视角。
看不到车辆侧面结构。

【构图】（全景战场一镜）
画面下方：我方两辆坦克并肩，炮口朝上——左侧蓝色坦克，右侧浅绿色坦克。
画面上方至中上：敌方三类单位推进，各用纯色涂装——
黑色重装坦克（体型更大、装甲厚重）、白色军用吉普车（轻型四轮）、红色坦克。
画面中央偏下：鹰形徽章基地，砖墙环护。
战场铺满砖墙残骸、钢铁障碍、稀疏草地与浅水泥地。
中景有 1～2 处柔和像素圆形爆炸（乳白核心 + 琥珀外圈 + 淡灰烟），以及少量曳光弹轨迹。
轻雾与尘埃增加氛围，但仍保持单位可读性。
本帧不要出现标题文字「AI TANK」（标题留给视频末段）。

【主体设计】
坦克结构仍方正、可辨《坦克大战》DNA，但边角可略圆、装甲块略软。
履带、炮塔、炮管层次清晰，远距离可辨。
我方：左蓝、右浅绿；饱和度适中、对比足够。
敌方（每车只用一种纯色，禁止同车混色或渐变拼色）：
- 黑色重装坦克：主战敌方，体型偏大。
- 白色军用吉普车：轻型侦察 / 突击车，四轮，外形与坦克明显区分。
- 红色坦克：中型敌方，纯红涂装醒目。
基地：方形结构 + 中央鹰徽，不出现人物。

【光照】
顶部柔光，环境遮蔽轻柔。
阴影淡、边缘软，爆炸局部提亮但不过曝。
不要强烈体积光与镜头光晕。

【禁止项】
不要真人、面部、血腥。
不要国旗、真实军徽、UI、血条、准星、水印、字幕。
不要卡通 Q 版夸张变形、赛博霓虹城、太空站。
不要分镜拼贴、四格漫画、UI 边框。
