# 《AI TANK》通关结局 — 漫画分镜自由发挥版

为 Godot 游戏《AI TANK》生成通关结局动画。题材：通关胜利。漫画 / 图形小说动态分镜，自由发挥。
不依赖参考图。

【必须保留】
- 蓝绿双坦克幸存；结尾 `MISSION CLEAR`（可加 `AI TANK`）。
- 1920×1080，约 10～12 秒。基地若出现应幸存。

【风格方向（尽量自由）】
收束页气质：大远景一格、双车特写一格、标题跨页感均可。
墨线可更干净、网点更柔；或用「最后一格全黑只留标题」等漫画收尾手法。
短暂闪回交火格可以有，但最后必须落到安静胜利。

【叙事】
余烬格 → 护卫 / 定格格 → 标题格。分格数量与转场任你定。

【禁止】
真人实拍、血腥、真实国旗/军徽、游戏 HUD、水印、长句旁白、礼花狂欢、无关题材。

【用途】
可选 Ending 变体。
