# 《AI TANK》开场参考图 — 高精度现代像素风

生成一张用于《AI TANK》开场动画的参考静帧（风格 / 高潮构图锁定图；不作视频首帧）。

【输出规格】
分辨率：1920×1080（16:9）。
单张静帧，非序列、非拼图。
文件命名建议 `tank-opening-ref.png`。

【用途】
作为后续开场视频的风格、配色、单位造型与高潮构图锁定参考（不作 I2V 首帧）。
画面应是「双方交火高潮定格」瞬间，信息完整，供视频中后段定格对齐。

【美术风格】
高精度现代像素风（High-Res / Modern Pixel Art）。
细节清晰，像素块感适中，有现代独立游戏质感。
军事科幻风：金属装甲、履带、能量指示灯、工业警示条纹。
整体调色偏冷：灰绿战场、蓝与浅绿我方装甲、黑色重装坦克 / 白色吉普车 / 红色坦克、橙红爆炸点缀。
不要写实电影级 CGI，不要低清 8-bit 马赛克糊片。

【视角要求】
严格正交俯视（90° 垂直向下）。
镜头正对战场顶部。
没有透视、没有倾斜、没有 45° / 等距视角。
看不到车辆侧面结构。

【构图】（全景战场一镜）
画面下方：我方两辆坦克并肩，炮口朝上——左侧蓝色坦克，右侧浅绿色坦克。
画面上方至中上：敌方三类单位推进，各用纯色涂装——
黑色重装坦克（体型更大、装甲厚重）、白色军用吉普车（轻型四轮）、红色坦克。
画面中央偏下：鹰形徽章基地，砖墙环护。
战场铺满砖墙残骸、钢铁障碍、稀疏草地与浅水泥地。
中景有 1～2 处像素风圆形爆炸（白黄核心 + 橙红外圈 + 灰烟），以及少量曳光弹轨迹。
轻微战场尘烟，气氛紧张。
本帧不要出现标题文字「AI TANK」（标题留给视频末段）。

【主体设计】
坦克结构方正，具有经典《坦克大战》识别度。
履带、炮塔、炮管层次分明，远距离仍可辨认。
我方：左蓝、右浅绿；颜色饱和、对比清晰。
敌方（每车只用一种纯色，禁止同车混色或渐变拼色）：
- 黑色重装坦克：主战敌方，体型偏大。
- 白色军用吉普车：轻型侦察 / 突击车，四轮，外形与坦克明显区分。
- 红色坦克：中型敌方，纯红涂装醒目。
基地：方形结构 + 中央鹰徽，不出现人物。

【光照】
顶部均匀主光。
柔和环境遮蔽，阴影较弱。
爆炸处可有短暂局部过亮，但整体不要电影级体积光。

【禁止项】
不要真人、面部、血腥。
不要国旗、真实军徽、UI、血条、准星、水印、字幕。
不要卡通 Q 版、赛博霓虹城、太空站。
不要分镜拼贴、四格漫画、UI 边框。
