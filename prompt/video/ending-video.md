# 《AI TANK》通关结局 — 视频 Prompt

生成一段用于 Godot 游戏《AI TANK》的通关结局动画视频。游戏是军事科幻风、高精度像素风的 Top-Down 坦克大战。
直接按本提示词生成完整视频，不依赖参考图、不使用 I2V 首帧锁定。
情绪与开场形成对照：开场是「敌袭逼近 → 迎战决心」；本片是「残局扫清 → 基地幸存 → 胜利落版」。

【输出规格】
分辨率：1920×1080（16:9）。
时长：约 10～12 秒。
帧率：24 或 30 FPS。

【美术风格】
高精度现代像素风（High-Res / Modern Pixel Art）。
细节清晰，像素块感适中，有现代独立游戏质感。
军事科幻风：金属装甲、履带、能量指示灯、工业警示条纹。
整体调色偏冷：灰绿战场、蓝与浅绿我方装甲、黑色重装坦克残骸 / 白色吉普车残骸 / 红色坦克残骸。
胜利氛围用柔和金橙余晖与能量光边点缀，避免刺眼霓虹。
不要写实电影级 CGI，不要低清 8-bit 马赛克糊片，不要换另一种画风。

【视角与镜头】
严格正交俯视（90° 垂直向下），全程同一机位语言。
可轻微推拉与平移，运动平滑、偏舒缓。
禁止透视、倾斜、45° / 等距视角。
禁止第一人称、禁止贴近炮管主观镜头、禁止过度抖动手持摄影。
禁止改成侧视或史诗倾斜镜头。

【单位与场景】
我方：左蓝坦克、右浅绿坦克；颜色饱和、对比清晰；结构方正，经典《坦克大战》识别度；装甲完好、略有战斗磨损但不破损。
敌方残骸（每车只用一种纯色，禁止同车混色或渐变拼色）：
- 黑色重装坦克残骸：主战敌方残骸，体型偏大、冒烟熄火。
- 白色军用吉普车残骸：轻型侦察车残骸，四轮倾覆或静止。
- 红色坦克残骸：中型敌方残骸，纯红涂装仍可辨认。
基地：方形结构 + 中央鹰徽完好，砖墙环护，旗帜/能量灯微亮；不出现人物。
战场：砖墙缺口与钢铁障碍、稀疏草地与浅水泥地；零星像素风圆形爆炸余烟（白黄核心淡去 + 橙红外圈熄灭 + 灰烟上飘）。

【故事节拍】（按时长推进）
00～02 秒｜战后余烬
俯视残局战场：敌方三类残骸散布、远处最后几缕烟柱；无我方入镜。氛围由紧张转为安静。

02～05 秒｜双车清场
左蓝、右浅绿两车从下方缓缓驶入，并肩推进；履带碾过尘土，炮塔微转扫视。
零星敌方残存单位被最后几发曳光弹击毁，像素颗粒爆炸后化作残骸与烟。

05～08 秒｜基地幸存
镜头缓缓上移或轻推，鹰徽基地完整入镜，砖墙环护、能量灯亮起。
战场安静下来，仅余烟与扬尘；蓝绿双车停在基地前方偏下，呈护卫构图。

08～10 秒｜胜利定格
柔和金橙余晖扫过画面，定格到胜利构图：蓝绿双车下方、完好基地居中偏上、敌军残骸散布四周。
无新交火，仅光影与烟缓慢流动。

10～12 秒｜标题落版
画面略提亮或烟雾淡出，中央浮现标题：
MISSION CLEAR
副行小字（可选）：AI TANK
字体厚重、军事感、略带科幻描边或能量光边。
稳定停留约 1.5～2 秒后淡出或定格结束。

【运动与节奏】
镜头运动平滑、缓慢，比开场更从容。
坦克有重量感，收尾射击干脆，爆炸后迅速归于安静。
情绪：余烬 → 清场 → 安宁 / 胜利感。

【禁止项】
不要真人、面部、血腥、国旗、真实军徽。
不要 UI、血条、准星、水印、字幕旁白、滚动字幕。
不要卡通 Q 版、赛博霓虹城、太空站、烟花庆典、礼花乱飞。
不要超长空镜；10～12 秒讲完「余烬 → 清场 → 基地幸存 → 标题」。
不要偏离上述单位颜色与造型。
不要把基地炸毁；本片强调基地幸存与通关胜利。

【用途说明】
用作游戏通关结局 Ending（`scene/Ending.gd` → `VideoStreamPlayer`，资源路径 `res://assets/video/tank-ending.ogv`），播完后显示继续提示并返回主菜单。
