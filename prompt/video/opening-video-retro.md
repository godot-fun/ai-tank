# 《AI TANK》开场动画 — 复古街机 / CRT 自由发挥版

为 Godot 游戏《AI TANK》生成开场动画。题材：坦克大战。气质偏复古街机、CRT 扫描线、80–90 年代游戏预告或演示画面，自由演绎。
不依赖参考图。

【必须保留】
- 蓝与浅绿为我方坦克色；敌方可用黑 / 白 / 红等。
- 情绪：紧张逼近 → 交火或对峙 → 标题 `AI TANK`。
- 1920×1080，约 10～12 秒。（可在画面内模拟低分辨率像素，但输出仍为高清）

【风格方向（尽量自由）】
CRT 扫描线、轻微色差、磷光余晖、霓虹边、街机柜感、低饱和或高对比复古调色均可。
像素可更粗、更「老游戏」；也可是「现代机拍复古游戏画面」。
视角不限：俯视、侧视、假 3D、夸张透视皆可，但要统一。
可加入抽象 HUD 闪烁、得分跳字风格装饰，但不要真实可读的复杂 UI 面板。

【叙事】
用复古游戏演示的节奏讲开场冲突即可；转场可用闪屏、雪花、色块擦除等复古手法。

【禁止】
真人、血腥、真实国旗/军徽、现代写实 CGI 为主、水印、旁白解说长句、完全无坦克。

【用途】
可选 Opening 变体。
