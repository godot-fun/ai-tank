# 《AI TANK》通关结局 — 手绘插画自由发挥版

为 Godot 游戏《AI TANK》生成通关结局动画。题材：战后幸存与胜利。手绘插画气质，尽量自由发挥。
不依赖参考图。

【必须保留】
- 蓝与浅绿双坦克幸存；胜利情绪，结尾 `MISSION CLEAR`（可加 `AI TANK`）。
- 1920×1080，约 10～12 秒。基地若出现应幸存。

【风格方向（尽量自由）】
水彩余晖、厚涂暮色、水墨烟尘、绘本静帧活动化均可。
强调氛围与构图美，而非战术细节。风、光、尘、烟、旗帜等细节任你添加。
节奏舒缓；可用一镜到底的慢推，也可用几张「插画页」式转场。

【叙事】
余烬 → 安宁 / 护卫感 → 标题。具体场景任选。

【禁止】
真人照片、血腥、真实国旗/军徽、UI、水印、旁白、礼花喧闹、无关题材。

【用途】
可选 Ending 变体。
