# 《AI TANK》通关结局 — 氛围诗意 / 极简自由发挥版

为 Godot 游戏《AI TANK》生成通关结局动画。题材：幸存与胜利。允许高度抽象、诗意、极简。尽量自由发挥。
不依赖参考图。

【必须保留】
- 蓝 / 浅绿我方坦克意象可辨；情绪落在安宁、释然或静谧胜利。
- 结尾标题：`MISSION CLEAR`（可加 `AI TANK`）。
- 1920×1080，约 10～12 秒。

【风格方向（最大自由度）】
余烬光、薄雾、剪影双车、几何废墟、缓慢粒子、单色调、远景微小坦克、象征性「基地灯亮起」……任选。
可做成动态海报或实验短片；胜利感来自光与静，而非再打一场。
具体战场、天气、是否残骸、是否基地——全部开放。

【叙事】
一个安静的胜利意象 → 标题。少即是多。

【禁止】
真人面部、血腥、真实国旗/军徽、复杂 UI、水印、旁白、礼花喧闹、与胜利/坦克无关的纯抽象。

【用途】
可选 Ending 变体（偏艺术向）。
