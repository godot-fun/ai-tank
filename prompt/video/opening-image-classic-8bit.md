# 《AI TANK》开场参考图 — 经典 8-bit 复古风

生成一张用于《AI TANK》开场动画的参考静帧（风格 / 高潮构图锁定图；不作视频首帧）。

【输出规格】
分辨率：1920×1080（16:9）。
单张静帧，非序列、非拼图。
文件命名建议 `tank-opening-ref.png`。

【用途】
作为后续开场视频的风格、配色、单位造型与高潮构图锁定参考（不作 I2V 首帧）。
画面应是「双方交火高潮定格」瞬间，信息完整，供视频中后段定格对齐。

【美术风格】
经典 8-bit / 早期家用机像素风，致敬《坦克大战》街机与红白机时代。
色板有限（约 16～32 色观感），色块干净、边缘硬切，几乎无抗锯齿。
坦克与砖墙用大色块勾勒，细节靠轮廓与少量高光点，不做细密材质噪点。
配色偏怀旧 CRT：灰褐砖墙、军绿草地、纯蓝 / 纯绿我方、黑 / 白 / 红敌方、亮黄橙爆炸。
不要现代高分辨率「假像素」渲染，不要写实 CGI，不要模糊滤镜。

【视角要求】
严格正交俯视（90° 垂直向下）。
镜头正对战场顶部。
没有透视、没有倾斜、没有 45° / 等距视角。
看不到车辆侧面结构。

【构图】（全景战场一镜）
画面下方：我方两辆坦克并肩，炮口朝上——左侧蓝色坦克，右侧浅绿色坦克。
画面上方至中上：敌方三类单位推进，各用纯色涂装——
黑色重装坦克（体型更大、装甲厚重）、白色军用吉普车（轻型四轮）、红色坦克。
画面中央偏下：鹰形徽章基地，砖墙环护。
战场铺满砖墙残骸、钢铁障碍、稀疏草地与浅水泥地。
中景有 1～2 处像素风圆形爆炸（白黄核心 + 橙红外圈），几乎无灰烟层次，爆炸呈硬边色环。
本帧不要出现标题文字「AI TANK」（标题留给视频末段）。

【主体设计】
坦克结构极度方正，经典《坦克大战》剪影：履带矩形 + 炮塔方块 + 炮管直线。
远距离靠纯色块即可识别，不依赖细纹。
我方：左蓝、右浅绿；高对比、无渐变。
敌方（每车只用一种纯色，禁止同车混色或渐变拼色）：
- 黑色重装坦克：主战敌方，体型偏大。
- 白色军用吉普车：轻型四轮，外形与坦克明显区分（可用更小矩形车身）。
- 红色坦克：中型敌方，纯红涂装醒目。
基地：方形结构 + 中央鹰徽（可用简化像素鹰形），不出现人物。

【光照】
几乎无真实光照，平面色块为主。
可有 1 级简单高光偏移，禁止体积光与软阴影。

【禁止项】
不要真人、面部、血腥。
不要国旗、真实军徽、UI、血条、准星、水印、字幕。
不要卡通 Q 版、赛博霓虹城、太空站。
不要分镜拼贴、四格漫画、UI 边框。
不要电影级烟雾与粒子糊边。
