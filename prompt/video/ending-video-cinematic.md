# 《AI TANK》通关结局 — 电影感自由发挥版

为 Godot 游戏《AI TANK》生成一段通关结局动画。核心题材是战后幸存与胜利；构图、镜头、光影、环境细节尽量自由发挥。
不依赖参考图、不使用 I2V 首帧锁定。与开场对照：开场是压迫与迎战，本片是余烬与安宁。

【必须保留】
- 主题：战场扫清、我方幸存、胜利落版。
- 我方：蓝与浅绿两辆坦克完好（可轻微战损），最终呈护卫或并肩定格感。
- 可出现敌方残骸、熄火烟柱、完好或半毁的方形基地（有鹰徽更好，非必须）。
- 结尾中央标题：`MISSION CLEAR`，可选副行 `AI TANK`。
- 分辨率 1920×1080，时长约 10～12 秒。

【风格方向（请大胆演绎）】
电影感收束短片：余晖、尘埃、慢推、远景空镜均可。
允许透视与多机位切换，但节奏应比开场更从容。
胜利氛围用柔和金橙、冷蓝余烟、薄雾、光斑等皆可；避免刺眼霓虹狂欢。
画风自选一种并贯彻：高精度像素 / 半写实插画 / 电影渲染均可。

【叙事只需情绪弧线】
战后安静 → 我方现身或清场收尾 → 基地 / 幸存意象 → 标题。
具体战场风貌、天气、时刻（黄昏、黎明、雨后）由你决定。基地不要被彻底炸毁。

【禁止】
真人面部、血腥、真实国旗/军徽、UI、水印、旁白、礼花乱飞、无关题材。

【用途】
可选 Ending 变体（`tank-ending` 类资源）。
