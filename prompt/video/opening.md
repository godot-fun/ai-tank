# 《AI TANK》开场动画 — 生成流程

先生成参考图，再以参考图做 Image-to-Video，可降低视频生成成本并稳定角色颜色与构图。

1. 用下方【参考图 Prompt】出图 → 保存为 `assets/video/tank-opening-ref.png`（或同类路径）。
2. 将参考图作为首帧 / 风格参考，再用【视频 Prompt】生成 10～12 秒开场。
3. 成片转 OGV，放入 `assets/video/tank-opening-N.ogv`。

---

## 参考图 Prompt

生成一张用于《AI TANK》开场动画的参考静帧（Image-to-Video 首帧 / 风格锁定图）。

【输出规格】
分辨率：1920×1080（16:9）。
单张静帧，非序列、非拼图。
文件命名建议 `tank-opening-ref.png`。

【用途】
作为后续开场视频的构图、配色、单位造型锁定参考。
画面应是「双方交火高潮定格」瞬间，信息完整，便于模型据此延伸运动。

【美术风格】
高精度现代像素风（High-Res / Modern Pixel Art）。
细节清晰，像素块感适中，有现代独立游戏质感。
军事科幻风：金属装甲、履带、能量指示灯、工业警示条纹。
整体调色偏冷：灰绿战场、蓝与浅绿我方装甲、黑色重装坦克 / 白色吉普车 / 红色坦克、橙红爆炸点缀。
不要写实电影级 CGI，不要低清 8-bit 马赛克糊片。

【视角要求】
严格正交俯视（90° 垂直向下）。
镜头正对战场顶部。
没有透视、没有倾斜、没有 45° / 等距视角。
看不到车辆侧面结构。

【构图】（全景战场一镜）
画面下方：我方两辆坦克并肩，炮口朝上——左侧蓝色坦克，右侧浅绿色坦克。
画面上方至中上：敌方三类单位推进，各用纯色涂装——
黑色重装坦克（体型更大、装甲厚重）、白色军用吉普车（轻型四轮）、红色坦克。
画面中央偏下：鹰形徽章基地，砖墙环护。
战场铺满砖墙残骸、钢铁障碍、稀疏草地与浅水泥地。
中景有 1～2 处像素风圆形爆炸（白黄核心 + 橙红外圈 + 灰烟），以及少量曳光弹轨迹。
轻微战场尘烟，气氛紧张。
本帧不要出现标题文字「AI TANK」（标题留给视频末段）。

【主体设计】
坦克结构方正，具有经典《坦克大战》识别度。
履带、炮塔、炮管层次分明，远距离仍可辨认。
我方：左蓝、右浅绿；颜色饱和、对比清晰。
敌方（每车只用一种纯色，禁止同车混色或渐变拼色）：
- 黑色重装坦克：主战敌方，体型偏大。
- 白色军用吉普车：轻型侦察 / 突击车，四轮，外形与坦克明显区分。
- 红色坦克：中型敌方，纯红涂装醒目。
基地：方形结构 + 中央鹰徽，不出现人物。

【光照】
顶部均匀主光。
柔和环境遮蔽，阴影较弱。
爆炸处可有短暂局部过亮，但整体不要电影级体积光。

【禁止项】
不要真人、面部、血腥。
不要国旗、真实军徽、UI、血条、准星、水印、字幕。
不要卡通 Q 版、赛博霓虹城、太空站。
不要分镜拼贴、四格漫画、UI 边框。

## 视频 Prompt

生成一段用于 Godot 游戏《AI TANK》的开场动画视频。游戏是军事科幻风、高精度像素风的 Top-Down 坦克大战。

【参考图】
必须严格基于已生成的开场参考图（`tank-opening-ref.png`）做 Image-to-Video。
锁定参考图中的：俯视构图、战场地块、单位造型与纯色涂装、爆炸像素风格。
禁止擅自改色、换造型、改成侧视或透视镜头。

【输出规格】
分辨率：1920×1080（16:9）。
时长：约 10～12 秒。
帧率：24 或 30 FPS。
无声画面（BGM 由游戏单独播放）。
导出后转为 OGV，放入 `assets/video/`，命名建议 `tank-opening-N.ogv`。

【美术风格】
与参考图一致：高精度现代像素风、军事科幻、冷色战场。
不要写实电影级 CGI，不要低清 8-bit 马赛克糊片。

【视角与镜头】
全程保持正交俯视，与参考图同一机位语言。
可轻微推拉与平移，运动平滑。
禁止第一人称、禁止贴近炮管主观镜头、禁止过度抖动手持摄影。
禁止从参考图的俯视改成倾斜史诗镜头。

【故事节拍】（按时长推进；单位与颜色以参考图为准）
01～02 秒｜荒寂战场
从参考图同场景的空旷状态起：砖墙残骸、钢铁障碍、草地与水泥地，远处尘烟。

02～05 秒｜敌袭逼近
敌方三类单位从上方 / 两侧进入：黑色重装坦克、白色军用吉普车、红色坦克（各纯色）。
履带与车轮扬尘，炮塔微转；砖墙被打穿，像素颗粒爆炸。

05～08 秒｜我方迎战
左蓝、右浅绿两车从下方冲入并肩交火；曳光弹与圆形像素爆炸；鹰徽基地短暂入镜。

08～10 秒｜高潮定格
大爆炸闪光后烟雾散开，定格到接近参考图构图：蓝绿双车下方、敌军上方、基地居中。

10～12 秒｜标题落版
画面渐暗或烟雾淡出，中央浮现标题：
AI TANK
字体厚重、军事感、略带科幻描边或能量光边。
稳定停留约 1.5～2 秒后淡出或定格结束。

【运动与节奏】
镜头运动平滑、缓慢，避免眩晕。
坦克有重量感，炮弹快、爆炸干脆。
情绪：紧张 → 冲突 → 决心 / 史诗感。

【禁止项】
不要真人、面部、血腥、国旗、真实军徽。
不要 UI、血条、准星、水印、字幕旁白。
不要卡通 Q 版、赛博霓虹城、太空站。
不要超长空镜；10～12 秒讲完「战场 → 交火 → 标题」。
不要偏离参考图的单位颜色与造型。

【用途说明】
用作游戏启动 Opening（`scene/Main.gd` → `VideoStreamPlayer`），播完进入主菜单「AI TANK」。
