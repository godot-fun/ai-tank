生成一段用于 Godot 游戏《AI TANK》的开场动画视频。游戏是军事科幻风、高精度像素风的 Top-Down 坦克大战。

【输出规格】
分辨率：1920×1080（16:9）。
时长：约 10～12 秒。
帧率：24 或 30 FPS。
无声画面（BGM 由游戏单独播放）。
导出后转为 OGV，放入 `assets/video/`，命名建议 `tank-opening.md` 对应成片 `tank-opening-N.ogv`。

【美术风格】
高精度现代像素风（High-Res / Modern Pixel Art）。
细节清晰，像素块感适中，有现代独立游戏质感。
军事科幻风：金属装甲、履带、能量指示灯、工业警示条纹。
整体调色偏冷：灰绿战场、蓝与浅绿我方装甲、黑色重装坦克 / 白色吉普车 / 红色坦克、橙红爆炸点缀。
不要写实电影级 CGI，不要低清 8-bit 马赛克糊片。

【视角与镜头】
以正交俯视战场为主（贴近游戏实际视角），可穿插轻微推拉与平移。
允许开场 1～2 秒从略带倾斜的史诗俯瞰平滑过渡到正俯视。
禁止第一人称、禁止贴近炮管的主观镜头、禁止过度抖动手持摄影。

【故事节拍】（按时长推进，节奏干脆）
01～02 秒｜荒寂战场
俯视空旷战场：砖墙残骸、钢铁障碍、稀疏草地与浅水泥地。
远处尘烟缓缓升起，气氛压抑。

02～05 秒｜敌袭逼近
敌方单位从画面上方或两侧推进，三类单位同时出场、各用纯色涂装：
黑色重装坦克（体型更大、装甲厚重）、白色军用吉普车（轻型、机动快）、红色坦克。
履带与车轮碾过地面扬起细尘，炮塔微微转动。
砖墙被炮弹打穿，碎块飞溅（像素颗粒感爆炸，非写实火球）。

05～08 秒｜我方迎战
两辆我方坦克从画面下方并肩冲入：左侧蓝色坦克，右侧浅绿色坦克。
双方交火：曳光弹轨迹清晰，爆炸呈圆形扩散的像素火焰与灰烟。
可短暂出现中央鹰形徽章基地被砖墙环护的画面，强调“守护基地”主题。

08～10 秒｜高潮定格
一次较大的爆炸闪光后，烟雾散开。
蓝绿两车并肩停在战场下方或中央，轮廓清晰，形成双人搭档定格。

10～12 秒｜标题落版
画面渐暗或烟雾淡出，中央浮现标题文字：
AI TANK
字体厚重、军事感、略带科幻描边或能量光边。
标题稳定停留约 1.5～2 秒后淡出或定格结束，便于衔接到主菜单。

【主体设计】
坦克结构方正，具有经典《坦克大战》识别度。
履带、炮塔、炮管层次分明，远距离仍可辨认。
我方双人组：左侧蓝色坦克，右侧浅绿色坦克；颜色饱和、对比清晰，便于识别。
敌方三类单位（每车只用一种纯色，禁止同车混色或渐变拼色）：
- 黑色重装坦克：主战敌方，体型偏大、装甲厚重。
- 白色军用吉普车：轻型侦察 / 突击车，四轮结构，与坦克外形明显区分。
- 红色坦克：中型敌方坦克，纯红涂装醒目。
基地：方形结构 + 中央鹰徽，不出现人物。

【光照与氛围】
顶部均匀主光 + 轻微战场烟雾散射。
爆炸瞬间允许短暂过曝闪光，随即恢复。
阴影较弱，不要电影级体积光堆砌。

【运动与节奏】
镜头运动平滑、缓慢，避免眩晕。
坦克移动有重量感，炮弹飞行快、爆炸干脆。
整体情绪：紧张 → 冲突 → 决心 / 史诗感。

【禁止项】
不要真人、不要面部特写、不要血腥肢解。
不要国旗、真实国家标识、现实军徽。
不要 UI 按钮、血条、准星、水印、字幕旁白。
不要卡通 Q 版、不要赛博霓虹城市、不要太空站外景。
不要超长拖沓空镜；10～12 秒内必须讲完“战场 → 交火 → 标题”。

【用途说明】
用作游戏启动后的 Opening 过场（`scene/Main.gd` → `VideoStreamPlayer`），播完后进入主菜单「AI TANK」。
