# 《AI TANK》开场动画 — 视频 Prompt

生成一段用于 Godot 游戏《AI TANK》的开场动画视频。游戏是军事科幻风、高精度像素风的 Top-Down 坦克大战。
直接按本提示词生成完整视频，不依赖参考图、不使用 I2V 首帧锁定。

【输出规格】
分辨率：1920×1080（16:9）。
时长：约 10～12 秒。
帧率：24 或 30 FPS。

【美术风格】
高精度现代像素风（High-Res / Modern Pixel Art）。
细节清晰，像素块感适中，有现代独立游戏质感。
军事科幻风：金属装甲、履带、能量指示灯、工业警示条纹。
整体调色偏冷：灰绿战场、蓝与浅绿我方装甲、黑色重装坦克 / 白色吉普车 / 红色坦克、橙红爆炸点缀。
不要写实电影级 CGI，不要低清 8-bit 马赛克糊片，不要换另一种画风。

【视角与镜头】
严格正交俯视（90° 垂直向下），全程同一机位语言。
可轻微推拉与平移，运动平滑。
禁止透视、倾斜、45° / 等距视角。
禁止第一人称、禁止贴近炮管主观镜头、禁止过度抖动手持摄影。
禁止改成侧视或史诗倾斜镜头。

【单位与场景】
我方：左蓝坦克、右浅绿坦克；颜色饱和、对比清晰；结构方正，经典《坦克大战》识别度。
敌方（每车只用一种纯色，禁止同车混色或渐变拼色）：
- 黑色重装坦克：主战敌方，体型偏大、装甲厚重。
- 白色军用吉普车：轻型侦察 / 突击车，四轮，外形与坦克明显区分。
- 红色坦克：中型敌方，纯红涂装醒目。
基地：方形结构 + 中央鹰徽，砖墙环护，不出现人物。
战场：砖墙残骸、钢铁障碍、稀疏草地与浅水泥地；像素风圆形爆炸（白黄核心 + 橙红外圈 + 灰烟）。

【故事节拍】（按时长推进）
00～02 秒｜荒寂战场
从空旷战场起：仅地形与残骸、远处尘烟；无单位入镜。

02～05 秒｜敌袭逼近
敌方三类单位从上方 / 两侧进入：黑色重装坦克、白色军用吉普车、红色坦克。
履带与车轮扬尘，炮塔微转；砖墙被打穿，像素颗粒爆炸。

05～08 秒｜我方迎战
左蓝、右浅绿两车从下方冲入并肩交火；曳光弹与圆形像素爆炸；鹰徽基地短暂入镜。

08～10 秒｜高潮定格
大爆炸闪光后烟雾散开，定格到高潮构图：蓝绿双车下方、敌军上方、基地居中偏下。

10～12 秒｜标题落版
画面渐暗或烟雾淡出，中央浮现标题：
AI TANK
字体厚重、军事感、略带科幻描边或能量光边。
稳定停留约 1.5～2 秒后淡出或定格结束。

【运动与节奏】
镜头运动平滑、缓慢，避免眩晕。
坦克有重量感，炮弹快、爆炸干脆。
情绪：紧张 → 冲突 → 决心 / 史诗感。

【禁止项】
不要真人、面部、血腥、国旗、真实军徽。
不要 UI、血条、准星、水印、字幕旁白。
不要卡通 Q 版、赛博霓虹城、太空站。
不要超长空镜；10～12 秒讲完「战场 → 交火 → 标题」。
不要偏离上述单位颜色与造型。

【用途说明】
用作游戏启动 Opening（`scene/Main.gd` → `VideoStreamPlayer`），播完进入主菜单「AI TANK」。
