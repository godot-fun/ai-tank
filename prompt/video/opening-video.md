# 《AI TANK》开场动画 — 视频 Prompt

生成一段用于 Godot 游戏《AI TANK》的开场动画视频。游戏是军事科幻风、高精度像素风的 Top-Down 坦克大战。

【参考图】
必须严格基于已生成的开场参考图（`tank-opening-ref.png`）锁定风格与最终构图。
参考图是「双方交火高潮定格」，只作风格 / 配色 / 单位造型 / 尾段构图参考。
禁止把参考图当作视频首帧（I2V start frame）——否则 0～1 秒已是满场交火，与「空场起势」节拍割裂。

锁定参考图中的：俯视构图语言、战场地块、单位造型与纯色涂装、爆炸像素风格。
禁止擅自改色、换造型、改成侧视或透视镜头。

【首帧要求】
第 0 帧应为同场景的空旷战场：砖墙残骸、钢铁障碍、草地与水泥地、远处尘烟；无坦克、无吉普、无交火。
可用单独生成的空场图作 I2V 首帧；或用支持「风格参考、非首帧锁定」的生成方式。
切勿上传高潮参考图作为 start / first frame。

【输出规格】
分辨率：1920×1080（16:9）。
时长：约 10～12 秒。
帧率：24 或 30 FPS。
无声画面（BGM 由游戏单独播放）。
导出后转为 OGV，放入 `assets/video/`，命名建议 `tank-opening-N.ogv`。

【美术风格】
与参考图一致：保持参考图已选定的风格语言（像素粒度、配色、爆炸表现）。
不要擅自换成另一种画风或写实电影级 CGI。

【视角与镜头】
全程保持正交俯视，与参考图同一机位语言。
可轻微推拉与平移，运动平滑。
禁止第一人称、禁止贴近炮管主观镜头、禁止过度抖动手持摄影。
禁止从参考图的俯视改成倾斜史诗镜头。

【故事节拍】（按时长推进；单位与颜色以参考图为准）
00～02 秒｜荒寂战场
从空旷战场起：仅地形与残骸、远处尘烟；无单位入镜。

02～05 秒｜敌袭逼近
敌方三类单位从上方 / 两侧进入：黑色重装坦克、白色军用吉普车、红色坦克（各纯色）。
履带与车轮扬尘，炮塔微转；砖墙被打穿，像素颗粒爆炸。

05～08 秒｜我方迎战
左蓝、右浅绿两车从下方冲入并肩交火；曳光弹与圆形像素爆炸；鹰徽基地短暂入镜。

08～10 秒｜高潮定格
大爆炸闪光后烟雾散开，定格到接近参考图构图：蓝绿双车下方、敌军上方、基地居中。

10～12 秒｜标题落版
画面渐暗或烟雾淡出，中央浮现标题：
AI TANK
字体厚重、军事感、略带科幻描边或能量光边。
稳定停留约 1.5～2 秒后淡出或定格结束。

【运动与节奏】
镜头运动平滑、缓慢，避免眩晕。
坦克有重量感，炮弹快、爆炸干脆。
情绪：紧张 → 冲突 → 决心 / 史诗感。

【禁止项】
不要真人、面部、血腥、国旗、真实军徽。
不要 UI、血条、准星、水印、字幕旁白。
不要卡通 Q 版、赛博霓虹城、太空站。
不要超长空镜；10～12 秒讲完「战场 → 交火 → 标题」。
不要偏离参考图的单位颜色与造型。
不要将高潮参考图设为 I2V 首帧。

【用途说明】
用作游戏启动 Opening（`scene/Main.gd` → `VideoStreamPlayer`），播完进入主菜单「AI TANK」。
