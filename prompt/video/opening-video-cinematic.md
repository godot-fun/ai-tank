# 《AI TANK》开场动画 — 电影感自由发挥版

为 Godot 游戏《AI TANK》生成一段开场动画。核心题材是军事科幻坦克战；其余构图、镜头、节奏、光影、环境细节交给你自由发挥。
不依赖参考图、不使用 I2V 首帧锁定。

【必须保留】
- 主题：坦克大战即将爆发 / 敌袭将至 / 迎战决心。
- 我方辨识：一蓝、一浅绿两辆主战坦克（可并肩、可前后、可分镜交替出现）。
- 敌方可用黑、白、红等鲜明敌对涂装；可出现坦克、轻型载具或抽象威胁。
- 结尾中央落版标题：`AI TANK`（厚重、军事或科幻感字体即可）。
- 分辨率 1920×1080，时长约 10～12 秒。

【风格方向（请大胆演绎）】
电影感军事短片 / 游戏预告片质感。
允许透视、低机位、侧视、缓慢推轨、环绕、俯冲、爆炸闪光后的缓推，不必拘泥正交俯视。
光影可戏剧化：体积光、尘雾、镜头光晕、剪影、冷暖对比均可。
画风可在「高精度像素」「半写实插画」「电影级渲染」之间自行选择一种并贯彻全片，保持统一即可。

【叙事只需情绪弧线，不必逐秒卡点】
紧张氛围建立 → 冲突或压迫感上升 → 我方亮相 / 迎战 → 标题落版。
具体场景（荒漠、废墟城、工业基地、夜战、暴雨、沙尘暴等）由你决定。

【禁止】
真人面部特写、血腥肢解、真实国旗/军徽、UI 血条准星、水印、旁白字幕、烟花庆典、完全无关题材（太空歌剧巨舰、纯赛博都市无坦克等）。

【用途】
可选 Opening 变体；播完进入主菜单「AI TANK」。
