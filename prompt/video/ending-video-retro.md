# 《AI TANK》通关结局 — 复古街机 / CRT 自由发挥版

为 Godot 游戏《AI TANK》生成通关结局动画。题材：通关胜利。复古街机 / CRT 气质，自由演绎。
不依赖参考图。

【必须保留】
- 蓝绿双坦克幸存或通关姿态；结尾 `MISSION CLEAR`（可加 `AI TANK` / `STAGE CLEAR` 感）。
- 1920×1080，约 10～12 秒。

【风格方向（尽量自由）】
老式通关画面氛围：闪烁标题、扫描线、像素烟花（克制）、得分滚动感（抽象即可）、磷光淡出。
也可做成「演示模式胜利回放」：慢速巡场、残骸静止、双车停在安全区。
画风与开场复古版尽量可成套，但不强制同镜头。

【叙事】
战后安静或通关庆祝的像素感收束 → 标题。避免现代烟花大片。

【禁止】
真人、血腥、真实国旗/军徽、写实 CGI 主导、水印、旁白、无关题材。

【用途】
可选 Ending 变体。
