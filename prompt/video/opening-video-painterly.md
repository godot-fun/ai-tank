# 《AI TANK》开场动画 — 手绘插画自由发挥版

为 Godot 游戏《AI TANK》生成开场动画。题材：军事科幻坦克战。以手绘插画 / 数字绘画短片气质自由发挥。
不依赖参考图。

【必须保留】
- 蓝与浅绿双坦克为我方；敌对单位可用鲜明对比色。
- 情绪弧线：荒寂或压迫 → 冲突将至 / 迎战 → 标题 `AI TANK`。
- 1920×1080，约 10～12 秒。

【风格方向（尽量自由）】
厚涂、水彩、水墨、粉彩、概念艺术绘本感均可——选定一种主调并贯彻全片。
笔触、纸纹、颜料边缘、溅墨、炭笔灰尘等纹理欢迎出现。
镜头可为缓慢平移的「活动插画」，也可有简单景深与层叠视差；不必正交俯视。
环境、天气、昼夜、构图完全开放。

【叙事】
用画面意境讲「战前一刻」即可，不必密集聚焦射击；若有交火，保持绘画感而非写实爆破。

【禁止】
真人照片、血腥、真实国旗/军徽、UI、水印、旁白、无坦克的纯风景片。

【用途】
可选 Opening 变体。
